# Student Management System

A console-based Java application to manage student records in memory.

## Features
- Add, remove, find students
- Update marks
- List by name or by marks (high to low)
- Report: top 3 scorers, average marks, failed count

## Concepts used
HashMap, equals/hashCode, Comparator, custom checked exceptions, Java Streams

## Project structure
model/ · exception/ · service/ · Main.java

## How to run
1. Install JDK 21
2. Open the project in VS Code
3. Run Main.java
